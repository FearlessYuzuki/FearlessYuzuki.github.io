Markdown 是一种轻量级标记语言，用纯文本格式编写文档，再转换为结构化的 HTML。本文覆盖日常写作中最常用的语法。

总结

  • 用空行分隔段落
  • 用空格控制缩进与嵌套
  • 代码块记得标注语言以获得高亮
  • 表格对齐用冒号：:--- 左对齐、:---: 居中、---: 右对齐

掌握以上语法，即可写出结构清晰、排版美观的 Markdown 文档。
