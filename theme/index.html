Theme

Komorebi — 木漏れ日

The Hexo theme powering this blog: Japanese-minimalist design with a tiling-window aesthetic (inspired by Hyprland / niri). Dark is the default theme; light is a warm off-white. Both share a high-contrast rainbow accent palette.

Theme configuration

Everything lives in themes/komorebi/_config.yml:

  • background — optional background image URL
  • menu — navigation menu (rendered by cat ./navigation.md on the homepage terminal)
  • search — local search (search.json generated at build time, no external service)
  • toc / copyright / mathjax / backToTop / visits — TOC, copyright notice, MathJax, back-to-top and visit-counter toggles
  • contacts — footer social links, format URL||icon. The E-mail icon opens a modal with the addresses from the email list (click to copy) instead of launching a mail client

Language switching

The EN / CN toggle (top-right) jumps to the /zh-CN/ prefixed routes.

  • Static pages (About / Friends / Projects / Gallery / Theme / 404) have real Chinese versions under source/zh-CN/, rendered natively by Hexo with language auto-detected via i18n_dir
  • Posts get /zh-CN/ copies from themes/komorebi/scripts/i18n.js (Chinese UI, original content; write a lang: zh-CN post in source/_posts/ for a translated version)
  • UI strings come from themes/komorebi/languages/; the Chinese file must be named zh-CN.yml (case-sensitive)

Search

  • Index: search.json (EN) / zh-CN/search.json (CN), generated by themes/komorebi/scripts/search.js
  • Entry points: the topbar magnifier, or Tag Search in the homepage terminal
  • Matches: title (highest weight), tags, categories, body text

Common tasks

  • New post: hexo new "Title"; front matter can carry categories / tags / description
  • Friends: edit the links: data in source/links/index.md
  • Projects: add projects: data in source/project/index.md
  • Gallery: edit the gallery: list in source/gallery/index.md, images live in source/img/gallery/
  • Categories: /categories/<name>/ appears once a post exists in that category
  • 404 page: built in, at source/404.md

Testing

npm test runs unit tests (i18n / search-index generators); npm run smoke checks the built output including a full dead-link scan. See TESTING.md at the repo root.
