主题

Komorebi — 木漏れ日

本博客使用的 Hexo 主题,日式极简 + 平铺窗口风格。深色主题为默认,浅色为暖白;两套主题共用高对比度彩虹色点缀。

配色方案

语义 深色(默认) 浅色
页面背景 #2C2420 暖深灰 #FDFBF7 暖白
文字 #F2EDE7 #2B2621
强调色 蓝 #60A5FA / 紫 #C084FC / 红 #F87171 蓝 #2563EB / 紫 #9333EA / 红 #DC2626
字体 Noto Sans Mono 粗体 同左

主题配置

所有配置位于 themes/komorebi/_config.yml:

  • background — 可选背景图 URL
  • menu — 导航菜单(首页终端窗口的 cat ./navigation.md 会渲染它)
  • search — 本地搜索(search.json 由构建时生成,无需外部服务)
  • toc / copyright / mathjax / backToTop / visits — 文章页目录、版权声明、数学公式、回到顶部、访问统计开关
  • contacts — 页脚社交链接,格式 URL||图标class;邮箱图标点击会弹出 email 列表中配置的地址(点击复制),不跳转邮件客户端

语言切换

站内 EN / CN 切换(顶栏右侧)会跳转到 /zh-CN/ 前缀路由。

  • 静态页面(关于/友链/项目/图集/主题/404)在 source/zh-CN/ 下有独立的中文版本,由 Hexo 原生生成,i18n_dir 自动识别语言
  • 文章由 themes/komorebi/scripts/i18n.js 生成 /zh-CN/ 副本(UI 为中文,正文为原文;如需中文译文,在 source/_posts/ 中撰写 lang: zh-CN 的文章)
  • UI 文案来自 themes/komorebi/languages/,中文翻译文件必须命名为 zh-CN.yml(大小写敏感)

搜索

  • 索引:search.json(EN)/ zh-CN/search.json(CN),由 themes/komorebi/scripts/search.js 生成
  • 入口:顶栏放大镜图标,或首页终端的 Tag Search
  • 匹配范围:标题(权重最高)、标签、分类、正文

常见操作

  • 新建文章:hexo new "标题",front matter 可加 categories / tags / description
  • 友链页:编辑 source/links/index.md 的 front matter,添加 links: 分组数据
  • 项目页:编辑 source/project/index.md,添加 projects: 数据
  • 图集页:编辑 source/gallery/index.md 的 gallery: 列表,图片放 source/img/gallery/
  • 分类页:在 Category 分类下有文章后,对应 /categories/<名称>/ 才会生成
  • 404 页:内置,位于 source/404.md

测试

npm test 运行单元测试(i18n / 搜索索引生成器),npm run smoke 在构建后做输出冒烟检查(含全站死链扫描)。测试说明见博客仓库根目录的 TESTING.md。
